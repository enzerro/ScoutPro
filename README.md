# Football Scout Platform

A professional football scouting platform built with React, React Router, and Vite.

## Features

- 🔍 Player database with 12,000+ players
- 📊 Advanced statistics and analytics
- 🔄 Player comparison tool
- 🌐 Multi-language support (Russian, English, Kyrgyz)
- 🎨 Dark mode support
- 📱 Responsive design

## Tech Stack

- **React 19** - UI library
- **React Router DOM 7** - Routing
- **Vite** - Build tool
- **TypeScript** - Type safety
- **Tailwind CSS** - Styling
- **Recharts** - Data visualization
- **Radix UI** - Accessible components
- **shadcn/ui** - Component library

## Getting Started

### Install Dependencies

```bash
pnpm install
```

### Run Development Server

```bash
pnpm dev
```

The app will be available at `http://localhost:5173`

### Build for Production

```bash
pnpm build
```

### Preview Production Build

```bash
pnpm preview
```

## Project Structure

```
src/
├── components/       # React components
├── pages/           # Page components
├── lib/             # Utilities and data
├── hooks/           # Custom hooks
├── globals.css      # Global styles
├── App.tsx          # Root component with routes
└── main.tsx         # Entry point
```

## Languages

The platform supports three languages:
- Russian (RU) - Русский
- English (EN) - English
- Kyrgyz (KY) - Кыргызча

Switch languages using the language selector in the navigation bar.
